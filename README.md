# Student Performance Prediction Using a Simple Average Scoring Method

## Scoring Demonstration

This standalone project keeps the simple student data input, validation, and average score calculation from the previous demonstration. It also includes a basic sidebar navigation layout.

### Formula

```text
Score = (Previous Grade + Attendance + Assignment Completion) / 3
```

The three indicators have equal importance because this is an unweighted average.

### Current Functionality

- Student information input
- Input validation
- Simple average calculation
- Score display
- Sidebar navigation

### Not Included

This small demonstration does not include performance categories, CSV processing, accuracy evaluation, machine learning, databases, authentication, or APIs.

### How to Run

Open a Windows Command Prompt or PowerShell terminal in this folder and run:

```text
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
